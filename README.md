# 連想ゲーム（THE ASSOCIATION GAME）

経済ニュースから市場への波及を6ステップで読み解く、連想力トレーニングゲームです。

**▶ https://rensougame.wonder-bros.com/**

## これは何か

「この金利のニュースは、どの会社の何に効くのか」を、当てずっぽうではなく**型**で辿れる
ようにするための練習台です。1本のニュースにつき6問、次の順番で考えます。

| | ステップ | 問うこと |
|---|---|---|
| ① | 本質を掴む | 見出しの表層ではなく、何が変わったのか |
| ② | 一次影響 | 直接に効く先はどこか |
| ③ | 相対優位／劣後 | 同じ業界でも誰が得をして誰が損をするか |
| ④ | 二次影響 | 一段先へどう波及するか（ここが本番） |
| ⑤ | 逆シナリオ | この連想が崩れる条件は何か |
| ⑥ | 検証ポイント | 仮説の急所を、どの一次情報で確かめるか |

解答後は、シニアアナリスト役の解説で「なぜその選択肢が罠なのか」まで読めます。

## 遊びコール

各ニュースには「この銘柄は上がるかも／下がるかも」という**遊びの予想**が3つ付いています。
ニュース当日を基準に、5営業日後（T+5）と20営業日後（T+20）で答え合わせをします。
市場全体（日経平均など）との比較も出るので、「相場が上がったから上がっただけ」と
「この材料で動いた」を切り分けられます。

外れたときに「すでに織り込まれていたのか」「逆シナリオが発動したのか」を考えるのが本題です。

## データについて

- 株価は Yahoo Finance から取得していますが、**公開しているのは騰落率だけ**です。
  実際の価格そのものは配信していません
- ニュースの見出しと出典元リンクは各媒体に帰属します。本文は転載していません
- 成績はブラウザ内（localStorage）にのみ保存され、サーバーには送信されません

## 技術メモ

ビルド不要のバニラ JS + CSS による SPA です。GitHub Pages で静的配信し、
記事と答え合わせのデータは `api/` 以下の JSON を読みます。
Service Worker を載せているのでオフラインでも起動し、スマホでは
「ホーム画面に追加」でアプリのように全画面で使えます。
